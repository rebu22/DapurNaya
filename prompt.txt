Buatkan model USE CASE lengkap untuk website catering "DapurNaya" di bawah ini.

KONTEKS WEBSITE
- Website company profile + pemesanan catering milik seorang Ibu (usaha rumahan).
- Dibangun dengan Vue 3 + Vite + Tailwind, di-deploy di Vercel.
- Halaman: Beranda (/), Layanan (/layanan), Paket Menu (/paket), Galeri (/galeri),
  Pemesanan (/pemesanan), dan 404.
- Fitur utama:
  1. Beranda: hero, daftar layanan unggulan, 2 langkah pemesanan, 3 menu andalan
     (Donat Kentang #1, Tumpeng Kuning #2, Bebek Rica-Rica #3), banner CTA
     "Hubungi Kami!", tombol WhatsApp mengambang.
  2. Layanan: 5 layanan (Kantor & Rapat, Hajatan & Syukuran, Harian & Rantangan,
     Ulang Tahun & Arisan, Pesan Antar Acara) + penjelasan fasilitas tiap layanan.
  3. Paket Menu: daftar paket dengan filter kategori (Semua, Box, Prasmanan,
     Syukuran, Langganan), tiap kartu ada harga, isi paket, dan tombol Pesan.
  4. Galeri: foto dokumentasi dengan filter kategori, klik foto membuka modal
     pratinjau.
  5. Pemesanan: form (nama, no. WhatsApp, jenis acara, tanggal, paket, jumlah
     porsi, catatan) dengan validasi, estimasi harga + DP 30% otomatis, tombol
     kirim pesanan via WhatsApp (pesan terisi otomatis), daftar FAQ, info kontak
     dan alamat dapur.
  6. Navigasi header (Beranda, Layanan, Paket Menu, Galeri, Pemesanan,
     Pesan Sekarang) dan footer (tautan, alamat, jam buka, copyright).
- Tidak ada login, pembayaran online, atau dashboard admin. Pemesanan selesai di
  WhatsApp (di luar sistem).

YANG SAYA MINTA
1. Identifikasi semua AKTOR (contoh: Pengunjung, Calon Pembeli, Sistem WhatsApp).
2. Daftar USE CASE beserta deskripsi singkat tiap use case.
3. Diagram use case dalam format Mermaid (blok kode ```mermaid) yang siap render.
4. Spesifikasi tiap use case: tujuan, aktor, prakondisi, alur utama (langkah
   bernomor), alur alternatif/eksepsi, dan pascakondisi.
5. Relasi <<include>> / <<extend>> jika ada (misalnya filter kategori
   meng-extend lihat daftar, validasi form meng-include hitung estimasi).

ATURAN
- Bahasa Indonesia.
- Hanya modeling, jangan menulis kode program.
- Jika ada asumsi, tulis di bagian "Asumsi" di akhir.
